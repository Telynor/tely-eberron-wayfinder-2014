# Changelog

## 0.1.0

Initial single-module conversion of the supplied 2018 Wayfinder prototype for 2014 rules. Includes 363 documents, complete original-page references, native advancements/activities, scripted contextual and combat rules, 38 tables and transparent Clawfoot artwork. Uses the published Tasha canonical registry; adds no classes or subclasses and no overlapping physical item/spell entry. Offline validation and LevelDB round-trip checks pass. Live Foundry acceptance remains pending.
